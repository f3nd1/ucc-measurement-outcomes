# Prompt: Environment Discovery

Inspect this repository and the local Frappe bench. Do not create or modify application code yet.

Report:

1. Frappe, ERPNext, Bench, Python and Node versions
2. Available sites and which one is safe for development
3. Installed custom apps
4. Relevant existing DocTypes and custom fields
5. Existing Quality Performance Outcomes, Quality Action and Quality Meeting structures
6. Existing public survey or form implementations
7. Existing D3 or diagram libraries
8. Whether background workers and scheduler are available
9. Recommended app name, Python package name and module name
10. Naming or compatibility risks

Write the result to `docs/11-environment-discovery.md` and update `docs/08-open-questions.md` only where the repository or environment provides a definite answer.
