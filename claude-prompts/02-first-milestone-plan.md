# Prompt: First Milestone Plan

Using the repository requirements, reference documents and completed environment discovery, propose the smallest complete vertical slice for Milestone 1.

The slice must demonstrate:

```text
Create a survey
→ add and reorder questions
→ save draft
→ publish one version
→ open a public link
→ submit one response
→ store one Submission
→ store one Answer per question
```

Provide:

- Exact files and DocTypes to create
- Permissions
- Data-flow diagram
- Test cases
- Verification commands
- Risks and assumptions

Do not implement until the plan is reviewed.
