# Start Here

## What does not exist yet

- Final DocTypes

## First task for Claude Code

Do not immediately build the entire product.

First inspect the local Frappe environment and report:

1. Frappe version
2. ERPNext version
3. Existing UCC custom apps
4. Existing relevant DocTypes
5. Existing Quality Performance Outcomes, Quality Action and Quality Meeting fields
6. Whether a development site is available
7. Recommended app package name
8. Any naming conflicts

Then propose the smallest complete first milestone.
