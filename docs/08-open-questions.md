1. Which Frappe and ERPNext versions are installed?
2. Can a separate custom app be installed on development, staging and production sites?
3. What is the exact existing DocType name for Quality Performance Outcomes?
4. Are objectives and compliance clauses already stored in reusable master records?
5. Which staff roles may create, approve and publish surveys?
6. Which respondents require anonymous links versus personal secure links?
7. Can respondents save and continue later?
8. What is the required data-retention period for survey responses?
9. Are response edits allowed after submission?
10. Which indices are required for the first release: SEQI only, or SEQI and SAPI?
11. What period structure should be used: month, term, quarter, academic year or configurable?
12. What is the minimum sample size and missing-data rule for each index?
13. Which existing D3 engine or diagram component is already used in SMS?
14. Should dashboards be fixed by administrators or configurable by ordinary staff?
15. Which exports must reproduce existing PDF layouts exactly?
