# User Flows

## Survey authoring

```text
Create survey
→ Add sections and questions
→ Add objectives, help text and response options
→ Preview desktop and mobile versions
→ Save draft
→ Send for review
→ Publish version
```

## Data collection

```text
Create campaign
→ Select target respondents
→ Generate public or secure links
→ Collect responses
→ Track starts, completions and response rate
→ Close campaign
```

## Objective and metric mapping

```text
Select survey version
→ Map each question to an objective
→ Map objective to clauses and standards
→ Assign reusable metric code
→ Define scoring and normalisation
→ Validate coverage
```

## Index calculation

```text
Select mapped metrics
→ Build dimensions visually
→ Set component weights
→ Validate formula
→ Publish index version
→ Calculate affected results
→ Save result snapshots
```

## Criterion 7 improvement loop

```text
Outcome below target
→ Drill down to weak component
→ Identify affected metric, question and population
→ Create Quality Action
→ Assign owner and due date
→ Review in Quality Meeting
→ Measure again
→ Verify effectiveness
```
