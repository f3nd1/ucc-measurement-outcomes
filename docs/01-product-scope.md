# Product Scope

## 1. Survey Studio

### Survey management

- Create from blank or template
- Rename, describe and categorise surveys
- Draft, review, approve, publish, close and archive
- Clone a survey or create a new version
- Compare versions
- Assign owner, reviewer and approver
- Set target population, response target and collection period

### Survey builder

- Drag question types into the survey
- Drag questions to reorder
- Short text, paragraph, email, telephone, number, currency, percentage, date and time
- Rating, Likert, Net Promoter Score, ranking and slider
- Single choice, multiple choice, dropdown and Yes/No
- Matrix and multiple-choice grid
- Section heading, page break, information statement and privacy notice
- File upload, signature, hidden context and calculated field
- Required questions and help text
- Validation and display logic
- Duplicate questions
- Copy and paste individual questions
- Copy sections between surveys
- Bulk-paste multiple questions from plain text
- Desktop and mobile preview
- Autosave and manual save draft
- Publish and generate share link

### Campaigns and data collection

- Public anonymous link
- Individual secure links
- QR code
- Opening and closing dates
- One response per respondent
- Save and continue later
- Automated reminder eligibility
- Response target and response-rate tracking
- Started, completed and abandoned status
- Public response submission
- One reportable answer row per question

### Survey analytics

- Response funnel
- Response rate against target
- Question completion and drop-off
- Automatic charts by question type
- Click chart segment to filter underlying responses
- Programme, intake, teacher and period breakdowns

## 2. Mapping Studio

### Objective and clause mapping

- Map survey questions to approved objectives
- Map objectives to primary and related clauses
- Flag applicable GD4, ISO 9001, PDPA, ISO 27001 and CSR requirements
- Table and node views
- Coverage and gap analysis
- Export matching the existing Survey Objective-Question Mapping structure

### Metric mapping

- Reusable metric codes
- Question-to-metric mapping across separate surveys and versions
- Metric groups and index dimensions
- Scale conversion to 0–100
- Reverse scoring
- Missing-value rules
- Minimum response count
- Mapping validation and impact preview

## 3. Index Studio

- Source, transformation, metric, dimension, index, context and output nodes
- D3 node dragging, connecting, panning and zooming
- Editable weights
- Validation that weights total 100%
- Circular-reference detection
- Draft and published versions
- Automatic server-side index calculation
- Explain-score drill-down
- SEQI and SAPI starter templates

## 4. Dashboard Studio

- KPI cards
- Target versus actual
- D3 trend visualisation
- Component contribution chart
- Programme, intake, teacher and period filtering
- Student-level drill-down
- Survey collection dashboard
- Criterion 7 outcome dashboard
- Create or link Quality Action
- Add result to Quality Meeting

## 5. Data Explorer

- Survey campaigns, submissions and answer rows
- Objective and metric mappings
- Metric, dimension and index results
- Select measures, rows, columns and filters
- Table, pivot, bar, line, Likert, heatmap and distribution outputs
- Save views and pin to dashboards
- CSV and JSON export suitable for ERPNext reporting
